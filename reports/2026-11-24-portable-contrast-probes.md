## Proposed mechanism

Use harmless fictional permission records with authoritative labels, independently authored schema families; no actual unauthorized actions or real targets. Keep exact same source/target models, features, labels, anchor texts, total activation forward passes, and linear probe training budget. Only change feature representation. In Bakker & Louizos' coordinates, r_j(x) = angular_distance(h(x), h(a_j)), where h denotes concatenated residual activations at a specified position. For matched anchors a_i+ and a_i- (same topic, different permission evidence), form d_i = r_i- - r_i+. Average over completion tokens if the protocol uses completion features. Fit logistic probe on d instead of r, freeze and transfer to a new checkpoint. No target labels in fitting; held-out target labels only in evaluation. No activation steering or changes to monitored model.

Derivation: if r_i+ = u_i + v_i+ and r_i- = u_i + v_i- for a shared nuisance offset u_i in relative-coordinate space, d_i = v_i- - v_i+ cancels that offset exactly. This is an assumption, not a property of angular distance under arbitrary additive shifts in raw activations. Also beta^T d = w^T r with pair weights w_i- = beta_i, w_i+ = -beta_i; thus this is a restriction of the ordinary linear hypothesis class, not added expressivity. If r+ = r- on all cases the information is lost. If evidence and topic interactions violate the shared-offset assumption, subtraction can remove useful signal. Pairing is an inductive bias, not a guaranteed improvement.

## Experimental contract (proposed, not executed)

After independent corpus authoring and lexical control, use 16 matched anchor pairs (32 texts) in a feasibility pilot. Compare ordinary 32-anchor logistic probe, matched contrast, shuffled disjoint pairs of the same anchors (same dimension and regularization convention), and a same-target supervised diagnostic upper comparator (not a zero-shot method). Standardize using source training only; select penalty and threshold on source development, freeze before target evaluation. Source and target checkpoints from the same verified open model family first; separate later cross-family validation. For the small feasibility pilot use at most 64 held-out records across >=4 independent schema families; no powered 1% FPR claim. Separate measured target FPR from recall at an empirically matched FPR (latter is a retrospective diagnostic). For larger validation preregister 10% FPR comparison, paired cluster bootstrap over independent schema families and separate checkpoint-level uncertainty; power from pilot, not guessed. Reject if matched contrast does not beat sham and ordinary anchor probe at comparable recall/FPR, if worst-family misses increase, or if source lexical cues explain success. No learned probe replaces the external authorization gate. The author-reported transfer gaps of 18.5 and 12.9 percentage points motivate the test but are not expected pilot effects.
